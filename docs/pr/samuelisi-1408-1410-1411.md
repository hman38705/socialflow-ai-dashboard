## Title

FE-029 / FE-031 / FE-032: Tooltip + Popover, DropdownMenu, and the Icon wrapper

## Body

Three Phase 2/3 design-system primitives. Each is a new file (plus one shared positioning
helper) with a co-located test. Nothing existing is modified except `index.html` (a comment).

**FE-029 - `Tooltip` and `Popover` (`src/components/ui/Tooltip.tsx`, `src/components/ui/Popover.tsx`, new)**

- `Tooltip` opens on hover **and** focus after `openDelay` (default 300ms), closes on
  blur/mouseleave after `closeDelay` (default 100ms) or Escape. It renders `role="tooltip"`
  and links itself to the trigger with `aria-describedby` only while open; content is not
  interactive (`pointer-events-none`).
- `Popover` is click-toggled, renders `role="dialog"` and moves focus into the panel, and
  closes on outside `pointerdown` or Escape (Escape restores focus to the trigger).
- Collision-aware placement lives in `src/components/ui/overlayPosition.ts`
  (`computePlacement`): it tries the preferred side, flips to the opposite side when that
  would overflow the viewport, then clamps the cross-axis so the element stays fully on
  screen. No external positioning library.
- Tests: focus opens the tooltip after the delay and wires `aria-describedby`; Escape and
  blur close it; `computePlacement` keeps / flips / clamps against stubbed rects; Popover
  opens on click, closes on outside pointerdown and on Escape with focus restored.

**FE-031 - `DropdownMenu` (`src/components/ui/DropdownMenu.tsx`, new)**

- `role="menu"` / `role="menuitem"`, opened by click or ArrowDown, closed by Escape (focus
  returns to the trigger), outside pointerdown, or Tab.
- ArrowUp/ArrowDown cycle through enabled items (disabled items are skipped), Home/End jump
  to the ends, and printable characters run a 500ms-window typeahead that jumps to the first
  item whose label starts with the buffer.
- Supports `{ type: 'separator' }` and `destructive` items (rose accent); disabled items are
  `aria-disabled` and not focusable.
- Trigger integration is via a render prop, so it can drive `DataTable` row actions, the
  sidebar user menu, and post-card actions without the menu owning the button markup.
- Tests: ArrowDown opens and focuses the first item; navigation skips the disabled item and
  wraps; typeahead; Escape closes and restores trigger focus; activating an item runs its
  handler and closes.

**FE-032 - `Icon` wrapper (`src/components/ui/Icon.tsx`, new; `index.html`)**

- `<Icon name="..." size="sm|md|lg" />` maps a curated `IconName` union to lucide-react
  components through one `ICONS` record, so icon imports stay in one place and
  tree-shakeable. An unknown `name` is a compile error.
- Decorative by default (`aria-hidden="true"`); passing `label` switches it to `role="img"`
  with that `aria-label` (the prop type requires `label` xor nothing).
- Material Symbols decision: **kept for now**. 14 files under `src/` still render
  `.material-symbols-outlined` spans, so the `<link>` in `index.html` cannot be dropped yet;
  an HTML comment there records why and points new code at `<Icon>`. Migrating those 14
  files is out of scope for this issue.
- Tests: `aria-hidden` by default; `label` yields `role="img"` with the accessible name;
  size maps to pixels; a `// @ts-expect-error` guards the unknown-name case.
