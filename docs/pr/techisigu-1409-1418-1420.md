## Title

FE-030 / FE-039 / FE-040 / FE-041: StatBadge + Badge, command palette, mobile nav, 404/403 pages

## Body

Design-system and app-shell primitives. All new files; nothing existing is modified.

**FE-030 - `StatBadge` and `Badge` (`src/components/ui/StatBadge.tsx`, `src/components/ui/Badge.tsx`)**

- `<StatBadge delta={number} precision?={1} />`: positive -> `ArrowUp` + `+X%` in
  `text-trend-up`, negative -> `ArrowDown` + `-X%` in `text-trend-down`, `0` -> `0%` in
  `text-gray-subtext` with no arrow. A visually-hidden `<span>` announces
  "up 12.5 percent" / "down 3.2 percent" / "no change" so colour is never the only signal.
  A trailing `.0` is trimmed.
- `<Badge variant="neutral|info|success|warning|danger" dot?>` - a pill `span` whose variant
  picks a token set; `dot` adds a decorative leading status dot.

**FE-039 - command palette (`src/components/layout/CommandPalette.tsx`)**

- `⌘K` / `Ctrl+K` toggles it; the shortcut is ignored when focus is in an
  `<input>`/`<textarea>`/`<select>`/contenteditable. `Esc` and a backdrop click close it.
- A `role="dialog"` modal with a `role="combobox"` input and a `role="listbox"` of
  `role="option"` items driven by `aria-activedescendant`; ArrowUp/Down cycle, Enter runs
  the highlighted item.
- Sections: **Navigation** (routes), **Actions** (New post -> `useComposer`, New webhook ->
  `/settings/webhooks`), **Search** (`SearchService.getSearch({ q })`, 250ms debounce).
- Each new query cancels the previous request (`CancelablePromise.cancel()`); a per-request
  sequence ref also drops any stale response that resolves out of order.
- Recent command ids persist in `localStorage` (`sf.cmdk.recent`, capped at 5).
- Tests: shortcut suppressed inside an input; 250ms debounce; a stale response resolving
  after a newer one never overwrites the newer results.

**FE-040 - mobile navigation drawer (`src/components/layout/MobileNav.tsx`)**

- An exported `useMediaQuery` hook (safe when `matchMedia` is missing) gates a 44x44
  hamburger to `max-width: 767px`. It opens a left drawer with the nav links (self-contained
  list, since `Sidebar` from FE-034 is on another branch).
- The drawer closes automatically when `useLocation().pathname` changes, and on `Esc`.
- Tap targets are `min-h-[44px]` / `h-11 w-11`.
- Tests: matchMedia-driven show/hide; a route change closes the drawer; the hamburger tap
  target size.

**FE-041 - 404 and 403 pages (`src/pages/NotFoundPage.tsx`, `src/pages/ForbiddenPage.tsx`)**

- Both use an inline `EmptyState`-style layout (FE-025 not on `master`) with a
  "Back to dashboard" `<Link>` and a "Contact support" `mailto:` link. `ForbiddenPage` is a
  `role="alert"` in the rose treatment.
- `NotFoundPage` fires exactly one `trackEvent('route.not_found', { path })` for a given
  path - a `useRef` guard keeps re-renders from re-firing it.
- Tests: link targets; `NotFoundPage` telemetry fires once across three re-renders;
  `ForbiddenPage` fires none.
